Effort

УровеньКогда по документации
lowпростые задачи, субагенты. У Haiku — чат и короткие операции с инструментами.
mediumбаланс; у Haiku 5.5 стартовая точка, включая агентный код.
highстарт для Fable 5.2 и Sonnet 5.5 (Sonnet — если задача не агентная и не критична к задержке).
xhighагентные задачи дольше 30 минут с бюджетом токенов в миллионах.
maxпотолок возможностей; для Fable — «измерить потолок».

Правила экономии (из Manage costs)

  • Sonnet справляется с большинством задач кода; Opus — для сложных архитектурных решений и многошаговых рассуждений.
  • Простым субагентам — Haiku.
  • Не оставляйте Opus моделью по умолчанию без причины.
  • /clear между задачами; CLAUDE.md короче 200 строк.
  • Командные агенты в plan mode расходуют примерно в 7 раз больше токенов.

Рабочая эвристика (гипотеза, не из доков)

ЗадачаПробуйте сначала
Переименование, правка SCSS, шаблонный кодSonnet, low–medium (или Haiku)
Фича на Spring/Angular с тестамиSonnet, medium–high
Spec, декомпозиция на тикеты, архитектураOpus, high, либо opusplan
Ревью и поиск баговSonnet high; если пропускает — Opus
Долгий автономный рефакторингOpus, xhigh

Правило калибровки: начинайте с более дешёвой комбинации и поднимайте уровень, только если результат слабый. В документации Sonnet 5 то же самое: при недодумывании первым шагом поднимите effort.
